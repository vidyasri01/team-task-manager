# team-task-manager
Role-based Team Task Management System built using MERN Stack with authentication, project management, task assignment, overdue tracking, and dashboard analytics.
# Team Task Manager

## Project Overview

Team Task Manager is a full-stack web application used to manage projects, assign tasks, track progress, and manage team members with role-based access.

The application allows Admins to create projects and tasks while Members can view and update assigned tasks.

---

# Features

- User Authentication (Login/Register)
- Role-Based Access (Admin / Member)
- Create Projects
- Create Tasks
- Assign Tasks to Team Members
- Task Status Tracking
- Dashboard with:
  - Total Tasks
  - Pending Tasks
  - Completed Tasks
  - Overdue Tasks
- Team Members Page
- Responsive UI
- MongoDB Database Integration
- Railway Deployment

---
